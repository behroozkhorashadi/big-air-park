# Big Air Park

A 3D trick park game you play in a web browser. Ride a snowboard, skis, a skateboard, a scooter or a BMX bike. Hit the ramps, grind the rails, fly through the Sky Zone portal, race Zoe, Max and Kai on the canyon track, play soccer and other sports, and answer math questions to win prizes.

## How to play on any computer

1. Download this repository: click the green **Code** button, then **Download ZIP**, and unzip it. If the computer has git, you can run `git clone` instead.
2. Double-click **`big-air-park.html`**. It opens in your web browser.
3. Click **Start**.

The computer needs an internet connection the first time the game loads, because the game loads its 3D engine (Three.js) and fonts from the web.

## Controls (keyboard)

| Key | What it does |
|---|---|
| ↑ ↓ ← → | ride, slow down and turn |
| Space | jump and spin a 360 |
| M / B / V | backflip / throw your ride in the air / 360 spin |
| 1, 2, 3, 4 | diagonal backflip toss, drop & chase, buttercup, drop & crazy backflips |
| N | near a rail: slide your ride under it and hop over |
| E | talk to people (Coach Rio starts a race!) |
| K | Colors & Stickers |
| T | travel to another planet |
| R | back to the start |
| H | show or hide all the keys |

A game controller works too. The full list of keys is in the game itself (press **H**).

## Files

- `big-air-park.html`: the whole game in one file.
- `BIG-AIR-PARK-SPEC.md`: how the game works inside, for anyone who wants to change it.

Saved progress (best score, prizes, colors) is stored in each browser, so a new computer starts fresh.
